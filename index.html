Configure sua API Key

Para usar o Carrossel Agent você precisa de uma chave da Anthropic.
Você cola uma vez — fica salva para sempre no navegador.

1
Acesse console.anthropic.com/settings/keys
2
Clique em "Create Key" e copie a chave
3
Cole abaixo e clique Salvar — pronto, nunca mais pede!
🔒 Sua chave fica salva só no seu navegador (localStorage).
Nunca é enviada para nenhum servidor além da Anthropic.
